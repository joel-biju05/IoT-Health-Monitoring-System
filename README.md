# IoT-Health-Monitoring-System
An IoT health tracker with ESP32 that monitors heart rate and SpO_2 using the MAX30102 and displays live vitals on an OLED screen. When abnormal vitals are detected or an SOS button is pressed, the system gets GPS coordinates via the NEO-6M and uses the SIM800L GSM to send an emergency SMS with a Google Maps location link and also a immediate call.
